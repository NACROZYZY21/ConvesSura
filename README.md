# ConvesSura

Web app React untuk mengonversi gambar (PNG/JPG) ke PDF — full client-side di browser.

## Fitur

- Upload banyak gambar sekaligus (drag & drop)
- Rename dan reorder gambar
- Auto-crop dokumen saat upload
- Preview, crop manual, dan filter "Perjelas Gambar"
- Convert terpisah atau gabung jadi 1 PDF multi-halaman
- Download PDF langsung (tanpa ZIP)

## Menjalankan

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```
